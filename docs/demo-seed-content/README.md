# Demo seed content: original technical write-ups

These 4 files exist for one purpose: giving the public demo's corpus
(`docs/DEMO-DEPLOYMENT.md`) content about Java, Spring Boot, Spring AI, and
Apache Kafka beyond this project's own documentation, so the demo can answer
general architecture/framework questions too, not just questions about this
specific repository.

**Written from scratch, not copied from any source.** Official documentation
(Oracle's for Java, Spring's for Spring Boot/Spring AI, Apache's for Kafka)
is copyrighted. Reproducing substantial portions of it into a database that
a public, unauthenticated demo then serves back to any visitor — including
quoting it in generated answers — would be redistributing that copyrighted
material at scale, not a fair-use quote. These files are original technical
explanations in the author's own words instead, covering the same
conceptual ground without reproducing anyone else's text.

Not technical documentation *of this project* (unlike everything else in
`docs/`) — kept in their own subdirectory for that reason, separate from
`docs/adr/` and the rest of the real project docs.
