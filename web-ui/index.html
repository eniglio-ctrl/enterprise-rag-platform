Enterprise RAG Platform

Upload documents, they're embedded and indexed automatically, then ask questions grounded in what you uploaded.

Public demo — a fixed set of documents is already indexed below; there's no login and no permanent document upload here (see the README for how to run the full stack locally with your own files). You can still attach an image to a single question using the 📎 button below.

Log in

Everything you upload and every question you ask is scoped to your tenant. Registering with no invitation token creates a brand-new tenant just for you; a teammate joins yours with an invitation you send them from the "Invite a teammate" panel after logging in.

Register

1. Upload a document

PDF, DOCX, Markdown, plain text, an image (PNG/JPEG/GIF/WebP — described by a vision model), or audio (MP3/WAV/M4A/OGG/FLAC — transcribed by a local Whisper server). Either way, the derived text is what gets indexed into pgvector, automatically after upload.

    Invite a teammate

    Creates a single-use invitation for your own tenant, valid for a limited time. Share the token with your teammate — they paste it into the "Invitation token" field when registering.

    2. Ask

    Ask a question about what you uploaded, or ask for a diagram/drawing/flow of an architecture or process described in it — the same box handles both, based on what you ask. Running on a local model with no GPU, so a diagram can take a minute or two. You can also attach an image (PNG/JPEG/GIF/WebP) to a single question — click 📎 or just paste a screenshot (Cmd/Ctrl+V) straight into the question box — described by a vision model to help answer just that question, never stored or indexed.
